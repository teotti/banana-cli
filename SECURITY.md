# Security policy

## Reporting a vulnerability

Please report security issues privately through
[GitHub's private vulnerability reporting](https://github.com/teotti/banana-cli/security/advisories/new),
not in a public issue or pull request.

Include the CLI version (`banana --version`), your platform, and steps to
reproduce. We aim to acknowledge reports within a few days.

## Supported versions

Only the latest release receives fixes. Run `banana upgrade` to update.

## Scope

This repository covers the `banana` CLI: credential storage, the installers,
and the release pipeline. Issues in the BananaSplit API or apps can be reported
the same way and will be passed on.
